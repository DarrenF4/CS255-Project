# CS255-Project

# Briefly summarize the DriverPass project. Who was the client? What type of system did they want you to design?
  The DriverPass project was created for a client named Liam, who wanted to create a system that filled a void in the market for training students for their driving test. The system would improve the success rate of driver testing by offering online classes, practice test material, and scheduling for in-person driving lessons. The system also needed to include role based access, ability to communicate with the DMV for updated driving requirements/material, secure account management, and admin tools.

# What did you do particularly well?
  Overall, I feel that my choice of wording and the way in which I broke ideas for the system down were strong. I feel that I did well in translating the users needs into clear requirements that are easy to read and follow.
